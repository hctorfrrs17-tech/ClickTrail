# Demonstration Quality Standard

Every public ClickTrail demonstration must be validated as a complete, reproducible user journey rather than as an isolated final action. Each new guide must start with ClickTrail’s automatic explicit navigation instruction, such as “Go to example.com,” then show each meaningful transition and finish at the stated result.

For browser-installation or download workflows, the exported PDF must show the source site, the repository or product page, the release or download page, and the exact official asset selected. Each step must use the screenshot and recorded coordinate from the same validation run. The reviewer must inspect the final PDF page-by-page, confirm the instructions are sequential, verify that the highlighted target matches the intended action, and only then publish the README, repository asset, or release attachment.

Privacy safeguards remain mandatory in every demonstration. A guide may continue after a navigation within the same origin, but it must stop immediately when the origin changes or a protected page is reached. Before publication, the reviewer must confirm that automatic pixelation and any manual redactions are permanently rendered in the exported PDF.
